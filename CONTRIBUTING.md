# Using the app

Read [docs/STUDENT_GUIDE.md](docs/STUDENT_GUIDE.md) before you change anything.

The course repository is read-only for students. Fork it, clone your fork, and push experiments to `origin`. The owner reviews a pull request opened from a fork. You cannot merge it, and you should not be given write or admin access on the upstream repo.

Do not force-push. Do not commit built APKs or the iOS zip. Do not put secrets in the repo. The debug keystore already in `android/app` is the public template keystore and is not a secret.
